## 📋 Contributing Screenshots

### To Add Screenshots:

1. **Capture the Screenshot**
   - Use browser screenshot tools
   - Or automated tools (Playwright, Puppeteer)
   - Follow quality guidelines in screenshots/README.md

2. **Name Appropriately**
   - Format: `##-description.png`
   - Example: `01-login.png`, `02-dashboard.png`

3. **Place in Correct Directory**
   - Landing: `landing/`
   - Client: `client/`
   - Admin: `admin/`
   - Staff: `staff/`
   - Provider: `provider/`

4. **Update Documentation**
   - Reference screenshot in relevant guides
   - Update screenshots/README.md status
   - Note in commit message
