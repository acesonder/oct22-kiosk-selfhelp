## Screenshot Naming Convention

Screenshots should be named descriptively:

Format: `{number}-{page-name}.png`

Example: `01-login.png`, `02-dashboard.png`, `03-assessment.png`

## Screenshot Guidelines

### Quality Standards:
- Resolution: Minimum 1920x1080 for desktop views
- Format: PNG (preferred) or JPEG
- Mobile views: 375x812 (iPhone X size) or 360x640 (Android)
- Tablet views: 768x1024 (iPad size)

### Content Guidelines:
- Use realistic but anonymized test data
- Show complete workflows
- Include both empty states and populated data
- Demonstrate error states and validation
- Show different status indicators

### Annotations:
- Consider adding arrows or highlights for complex features
- Number steps in multi-step processes
- Add callouts for important elements

## Taking Screenshots

### Using the Application:

1. Start the PHP development server:
   ```bash
   cd /path/to/kioskhelp
   php -S localhost:8080
   ```

2. Initialize the database through admin panel:
   - Navigate to `http://localhost:8080/admin/login.php`
   - Login with code: `079777`
   - Go to Database Tools
   - Click "Initialize Database"

3. Create test data:
   - Register test clients
   - Complete test assessments
   - Create sample referrals
   - Schedule test appointments

4. Capture screenshots:
   - Use browser's built-in screenshot tool
   - Or use tools like Snagit, Lightshot, or browser extensions
   - Ensure full page capture for long pages

### Automated Screenshots:

For consistency, consider using automated screenshot tools:
- Puppeteer (Node.js)
- Playwright (Node.js/Python)
- Selenium WebDriver

Example with Playwright:
```javascript
const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  
  await page.goto('http://localhost:8080/client/login.php');
  await page.screenshot({ path: 'client/01-login.png', fullPage: true });
  
  await browser.close();
})();
```
