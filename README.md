# Kiosk Self-Help Platform

A comprehensive web-based application designed to connect individuals in need with resources for homeless services, addiction recovery, mental health support, and other essential services. The platform serves three distinct user groups: clients seeking help, outreach staff managing cases, and service providers offering resources.

## Overview

This platform provides a modern, accessible interface for:
- **Clients** seeking help with housing, food, healthcare, employment, and other essential services
- **Outreach Staff** managing client cases and coordinating services
- **Service Providers** managing their organization's services and availability

## Quick Start

```bash
# Navigate to client application
cd client

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

The application will be available at `http://localhost:5173`

## Features

### 🤝 Client Portal
- Resource search and filtering
- Detailed service information
- Emergency contact access
- Quick filter categories

### 👨‍💼 Outreach Staff Portal
- Client management dashboard
- Case tracking and follow-ups
- Task management
- Quick tools for resource management

### 🏢 Service Provider Portal
- Service management and capacity tracking
- Referral management
- Analytics and reporting
- Organization profile management

## Technology Stack

- **Frontend**: React 19.1 with Vite
- **Routing**: React Router DOM
- **Styling**: CSS3 with responsive design
- **Build Tool**: Vite 7.1
